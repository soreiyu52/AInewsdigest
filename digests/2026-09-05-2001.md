## 🚀 主要なブレークスルー

- **Meta Muse Code がベータを卒業、Muse Spark 1.3 がリリース**：Meta の Muse Code は9月1日にベータから正式サービスに移行。マルチエージェントワークフロー、セッション間メッセージング、SDK開発者プレビューが導入。9月3日に Muse Spark 1.3 を発表し、DeepSWE v1.1 と Terminal-Bench 2.1 で Claude Opus 5 と GPT-5.6 Sol を上回る、またはタイするパフォーマンスを実現。[出典](https://research.meta.ai/blog/introducing-muse-code-and-muse-spark-1-2)

- **MIT による自動運転車 AI 説明性研究（CW-Net）が Nature に発表**：MIT とMotional の研究チームが、自動運転車の AI 推論プロセスを人間が理解可能な概念に変換するCW-Net（Concept-Wrapper Network）を開発。ラスベガスの実道でテスト実施し、安全運転者が車両の行動をより正確に予測できることを確認。9月2日に Nature に発表。[出典](https://news.mit.edu/2026/system-helps-humans-predict-when-self-driving-cars-will-make-mistakes-0902)

## 🛍️ 製品ローンチ・業界動向

- **HiddenLayer が Series B で $100M 調達**：AI セキュリティ企業 HiddenLayer が、Delta-v Capital 主導の Series B で $1億ドルを調達。9月2日発表。年間経常収益が過去1年で10倍以上成長し、数千万ドルの規模に。エージェント向けランタイムセキュリティと Agent Harness Security の強化に投資。[出典](https://www.securityweek.com/hiddenlayer-raises-100-million-for-ai-runtime-security/)

## 🔬 研究・セキュリティ

- **ソニー・ワーナーが Anthropic を著作権侵害で提訴**：Sony Music Publishing と Warner Chappell Music が、Anthropic と CEO Dario Amodei、共同創設者 Benjamin Mann を相手取り、「知的財産の大規模かつ露骨な盗用」として連邦裁判所に提訴。Claude モデル開発のための「数万曲」の違法ダウンロード・スクレイピングを指摘。1曲あたり最大 $150,000 の賠償を要求。[出典](https://www.musicbusinessworldwide.com/now-sony-music-publishing-and-warner-chappell-sue-anthropic-in-multi-billion-dollar-lawsuit-one-of-the-largest-and-most-blatant-ongoing-thefts-of-intellectual-property-in-history/)

- **MATS 研究者が普遍的なジェイルブレークテンプレートを発見**：合成トランスクリプト生成プロンプトを普遍的なジェイルブレークテンプレートに転換し、23モデル中特に脆弱な9モデルに対して84～100%の攻撃成功率を達成。生成AI のセキュリティ上の課題を明示。[出典](https://radicaldatascience.wordpress.com/2026/09/05/ai-news-briefs-bulletin-board-for-september-2026/)
