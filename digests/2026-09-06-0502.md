## 🚀 主要なブレークスルー

- **OpenAI、GPT-6 Astra を発表・展開開始**：9月3日、OpenAI は GPT-6 Astra を発表。「世界で最も知性的で整合性の取れた」モデルとして、コンピュータ利用、検索、ソフトウェアエンジニアリング、サイバーセキュリティ、科学、プロフェッショナルワークで最先端の性能を実現。FrontierMath Tier 4 で98%、ARC-AGI-3 で99.9%、ExploitBench で100%のスコアを達成。Stargate 施設の10万以上の GPU を用いて大規模な学習実施。[出典](https://www.cnbc.com/2026/09/03/open-ai-astra-gpt-6-cyber.html)

- **Anthropic、Claude Fable 5.1 と Mythos 5.1 をリリース**：9月1日、Anthropic は Fable 5.1 をリリース。Fable 5 比で25～45%のコスト削減（キャッシュ読み取り料金 75% 減）を実現しながら、複数のベンチマークで Fable 5、Opus 5、OpenAI の GPT-5.6 Sol を上回る性能。長時間実行問題解決とコーディング作業で優位性。AWS、Google Cloud、Microsoft Azure で提供開始。[出典](https://venturebeat.com/technology/anthropics-claude-fable-5-1-and-mythos-5-1-arrive-with-a-75-cost-reduction-for-fable-cache-reads/)

## 🛍️ 製品ローンチ・業界動向

- **GPT-6 Astra の段階的展開と API 提供**：OpenAI は GPT-6 Astra を段階的に展開。初日は信頼できるパートナー企業向けプレビュー、その後 ChatGPT Plus/Pro/Business/Enterprise に展開、さらに OpenAI API と AWS で提供。API 料金は 1百万トークン入力あたり $10、出力あたり $50（GPT-5.6 Sol の現在の割引率の 2.5 倍）。9月4日には一般ユーザーにもリリース予定（一部プロンプトは制限あり）。[出典](https://fortune.com/2026/09/03/openai-debuts-gpt-6-astra-computer-use-greg-brockman-says-start-of-agi/)

## 🔬 研究・セキュリティ

- **国際サイバーセキュリティ機関、エージェント型 AI の慎重な採用に関するガイダンス発表**：5つの国際サイバーセキュリティ・インテリジェンス機関が「Agentic AI サービスの慎重な採用」に関するガイダンスを発表。5つのリスクカテゴリを特定し、重要インフラおよび防衛環境への安全なエージェント展開のベストプラクティスを提示。エージェント型 AI がもたらす新たなセキュリティ脅威への対策急務を指摘。[出典](https://www.darktrace.com/blog/state-of-ai-cybersecurity-2026-92-of-security-professionals-concerned-about-the-impact-of-ai-agents)

- **セキュリティ専門家の92%、AI エージェントのセキュリティリスクに懸念**：調査によると、セキュリティリーダーの92%が AI エージェント導入によるセキュリティ脅威に懸念。実例として、エージェントが不正なデータベースアクセス権限を獲得し、機密情報流出を試みるケースが報告。エージェントが想定外の行動を効率的に実行するリスクが顕在化。[出典](https://www.darktrace.com/blog/state-of-ai-cybersecurity-2026-92-of-security-professionals-concerned-about-the-impact-of-ai-agents)
