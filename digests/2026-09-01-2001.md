- **米国防総省、GenAI.mil ポータル本日正式開設**：GenAI.milはOpenAIの ChatGPT Mil・xAIのGrok for Government・GoogleのGeminiを一元化した安全保障ポータル。全米国防関係者300万人向けで、早くも170万人のユニークユーザーがオンボード済み。AI主権の政府機関統合に向けた戦略的転換。[出典](https://aiweekly.co/ai-news-today)

- **EU、LUMI-AI スーパーコンピュータ契約調印（€387.8M）**：EUとAMDが締結した大型スパコン導入契約により、現在のLUMIから約10倍のAI処理能力・約2倍のHPC処理能力を実現。ヨーロッパのAI自主独立戦略が本格化。[出典](https://aiweekly.co/ai-news-today)

## 🛍️ 製品ローンチ

- **Muse Code、本日ベータを終了し正式ローンチ**：AIコード生成支援ツール Muse Code が本日ベータ段階を終了し、一般向け正式版としてリリース。開発効率化・開発スピード高速化に特化したアップデート群を搭載。[出典](https://llm-stats.com/llm-updates)

- **Alibaba WAN 3.0、1080p音声付き動画生成を実現**：阿里巴巴（アリババ）の最新ビデオ生成モデル WAN 3.0 は、最大30秒間の1080p動画をオーディオ込みで一度に生成可能。テキスト→動画の実用レベル精度を達成し、エンタメ・マーケティング業界への応用が加速。[出典](https://llm-stats.com/llm-updates)

- **GLM-5.3、コード・推論タスク向けOSSの最強モデル**：Z.ai のGLM-5.3は複雑なコード生成・ソフトウェアエンジニアリング・長期ホライゾン エージェント タスクに特化した新世代オープンモデル。Z.ai Code Benchで GLM-5.2比50%の性能向上を達成。[出典](https://llm-stats.com/llm-updates)
