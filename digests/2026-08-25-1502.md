## 🏢 業界アップデート

- **OpenAI対Appleの法的紛争、加速 — OpenAIが31ページの棄却申し立て提出**：OpenAIがAppleの営業秘密侵害訴訟に対し、31ページに及ぶ棄却申し立てを提出。「訴訟は根拠が腐っている」と主張し、Appleの訴因の妥当性を全面否定。AI業界のコーポレート戦争が法廷へ拡大。[出典](https://techcrunch.com/2026/08/20/openai-apple-legal-battle-motion-to-dismiss/)

- **INTERPOL、African Cyberthreat Assessment 2026報告 — AIが55%のサイバー犯罪に関与**：国際刑事警察機構（INTERPOL）がアフリカのサイバー脅威評価報告書を発表。報告されたサイバー犯罪の55%にAI技術が関与していることが判明。AI悪用の地政学的リスクが拡大。[出典](https://www.interpol.int/en/News-and-Events/News/2026/INTERPOL-African-Cyberthreat-Assessment)

- **コロラド州、AI チャットボット規制を全米初の法制化 — 未成年保護へ**：米コロラド州がAIチャットボットを特定規制する州法を全米で初めて制定。未成年者への有害コンテンツ配信防止を重点に、ユースケース別の規制枠組みを確立。州別AI規制の細分化が加速。[出典](https://leg.colorado.gov/bills/hb24-1158)

- **世界銀行、「World Development Report 2026」発表 — AI活用で発展途上国が100年分の開発を10年で実現可能**：世界銀行グループがWorld Development Report 2026を発表。AIを活用すれば、発展途上国が本来100年かかる開発を10年で達成できる可能性を示唆。ただし電力・接続性・スキル・制度整備が必須条件。[出典](https://www.worldbank.org/en/news/press-release/2026/08/04/world-development-report-2026-ai-development)

- **Anthropic、Claude Opus 5を同等モデルの約半額で提供**：AnthropicがClaude Opus 5を業界最安値レベルで提供開始。競合する最先端モデル比で50%程度のコスト削減を実現し、エンタープライズ市場での対抗軸を強化。[出典](https://www.anthropic.com/pricing)

- **Model Context Protocol、メジャーリリース候補版を公開**：AnthropicとOpenAI主導で開発されるModel Context Protocol（MCP）がリリース候補版を発表。AIエージェントがビジネスシステムへアクセスする標準規約として、エンタープライズ向けエージェント採用の基盤を整備。[出典](https://github.com/anthropics/mcp)
