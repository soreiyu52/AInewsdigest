- **Moonshot AI、Kimi K3正式発表：2.8兆パラメータで世界最大のオープンウェイトLLM、Frontend Code Arenaスコア1679で首位獲得** — 中国Moonshot AIが2.8兆パラメータのオープンウェイトモデルKimi K3を正式発表。1Mトークンのコンテキストを持つネイティブマルチモーダルモデルで、Arena.AIのFrontend Code Arenaでスコア1679を記録しClaude Fable 5やGPT-5.6 Solを上回った。全体性能ではFable 5・GPT-5.6 Solに次ぐ水準で、完全なモデルウェイトは7月27日公開予定。[出典](https://www.cnbc.com/2026/07/17/moonshot-ai-kimi-k3-model-openai-anthropic-china.html)

## 🛍️ 製品ローンチ

- **AnthropicがClaude Fable 5の有料ユーザー向け無料提供期間を7月19日まで延長** — 規制対応・新分類器追加に伴う追加時間確保のため、Anthropicは有料ユーザーへのClaude Fable 5無償提供（週次上限の最大50%）を7月19日23:59 PTまで延長すると発表。新たなサイバーセキュリティタスクブロック用分類器を追加した上でグローバル再デプロイを継続中。[出典](https://www.bleepingcomputer.com/news/artificial-intelligence/claude-fable-5-stays-free-for-paid-users-until-july-19-as-anthropic-buys-more-time/)

## 🔬 研究

- **ICML 2026発表「選択的活性スパーシティ」：タスク別パラメータ選択活性化でモデルを3倍効率化** — ICML 2026で発表された新トレーニング手法「selective activation sparsity（選択的活性スパーシティ）」が注目を集めている。タスクごとに最も関連性の高いパラメータのみを活性化することで、通常の3分の1サイズのモデルが推論ベンチマーク上で同等の性能を達成。訓練・推論コストの大幅削減につながる技術革新として評価されている。[出典](https://skycrumbs.com/blog/ai-research-july-2026)

- **WAIC 2026：中国の2026年ヒューマノイドロボット国内生産10万台突破を予測、AIスマホ・PCも非AI製品を初めて上回る見通し** — WAIC 2026の発表によれば、中国の2026年ヒューマノイドロボット年間生産台数が初めて10万台に達する見込み。工場・作業現場への実用普及が急加速しており、同年にはAIスマートフォンおよびAI PCの販売台数が非AI製品を初めて上回るという歴史的転換点にも達する予測が示された。[出典](https://www.prnewswire.com/news-releases/welcome-to-waic-2026--embrace-an-ai-empowered-better-life-302828456.html)
